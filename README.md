# Eisha Nadeem — Professional Portfolio

A responsive, editorial-style personal portfolio for Eisha Nadeem.

## Stack
- Semantic HTML
- CSS (responsive layout, custom design tokens, reduced-motion support)
- Vanilla JavaScript (mobile navigation and scroll reveals)
- Google Fonts: Playfair Display and DM Sans

## Local preview
Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deployment
This is a static site and can be deployed directly to Vercel with no build command and no environment variables.

## Content notes
The portfolio intentionally distinguishes platform knowledge from live campaign experience. It does not claim paid-ad campaign results or client outcomes.
